CONJUNTOS FIRST Y FOLLOW
========================
P:	FIRST = [eof, function, id, if, let, read, return, while, write]	FOLLOW = []
B:	FIRST = [id, if, let, read, return, while, write]	FOLLOW = [eof, function, id, if, let, read, return, while, write, }]
I:	FIRST = [=, lambda]	FOLLOW = [;]
T:	FIRST = [boolean, float, int, string]	FOLLOW = [id]
S:	FIRST = [id, read, return, write]	FOLLOW = [eof, function, id, if, let, read, return, while, write, }]
S2:	FIRST = [(, /=, =]	FOLLOW = [eof, function, id, if, let, read, return, while, write, }]
X:	FIRST = [!, (, cadena, entero, id, lambda, real]	FOLLOW = [;]
L:	FIRST = [!, (, cadena, entero, id, lambda, real]	FOLLOW = [)]
Q:	FIRST = [,, lambda]	FOLLOW = [)]
F:	FIRST = [function]	FOLLOW = [eof, function, id, if, let, read, return, while, write]
H:	FIRST = [boolean, float, int, string, void]	FOLLOW = [id]
A:	FIRST = [boolean, float, int, string, void]	FOLLOW = [)]
K:	FIRST = [,, lambda]	FOLLOW = [)]
C:	FIRST = [id, if, lambda, let, read, return, while, write]	FOLLOW = [}]
E:	FIRST = [!, (, cadena, entero, id, real]	FOLLOW = [), ,, ;]
E2:	FIRST = [<, ==, lambda]	FOLLOW = [), ,, ;]
R:	FIRST = [!, (, cadena, entero, id, real]	FOLLOW = [), ,, ;, <, ==]
R2:	FIRST = [+, lambda]	FOLLOW = [), ,, ;, <, ==]
U:	FIRST = [!, (, cadena, entero, id, real]	FOLLOW = [), +, ,, ;, <, ==]
U2:	FIRST = [/, lambda]	FOLLOW = [), +, ,, ;, <, ==]
V:	FIRST = [!, (, cadena, entero, id, real]	FOLLOW = [), +, ,, /, ;, <, ==]
V2:	FIRST = [(, lambda]	FOLLOW = [), +, ,, /, ;, <, ==]
